# Vida API skill

This repository is the source of truth for Vida's `vida-api` agent skill.

The skill teaches agents how to use Vida's API for contacts, tasks, Computer Agent setup and
operations, logs, and conversations. Edit and review [SKILL.md](./SKILL.md) here. The Vida OpenClaw
provisioner imports validated updates into its bundled workspace template automatically; do not
hand-edit the generated provisioner copy.
